# The Placerville Dog House — Website

A complete redesign of the website for **The Placerville Dog House**, a family-run,
kennel-free pet boarding facility on 5 acres outside downtown Placerville, CA.

Website generated by Goose Site Builder.

## Stack

Vanilla HTML, CSS, and JavaScript — no build step, no dependencies.
Open `index.html` in a browser, or serve the folder statically:

```bash
python3 -m http.server 8000
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Single-page site: hero, about, services, why-us, commitment, service area, FAQ, contact |
| `styles.css` | Design system (pine green / sand / amber palette), layout, responsive rules |
| `script.js` | Mobile nav, sticky header, scroll reveal, active-link tracking, FAQ accordion, contact form |
| `favicon.svg` | Paw-mark favicon |

  environment variables are used.
